# Perf Overlay

Windows용 작은 성능 오버레이. 화면 구석에 항상 떠 있으면서 CPU / RAM / GPU / 드라이브 여유 공간과 읽기·쓰기 상태를 보여준다.

- **클릭 통과**: 오버레이는 마우스를 무시하고 포커스도 가져가지 않는다. 게임이나 작업을 방해하지 않는다.
- **마우스 올리면 숨기기**: 커서가 오버레이 위로 오면 사라져 아래 화면이 보이고, 커서가 벗어나면 다시 나타난다. 설정 팝업에서 끌 수 있다.
- **일반 모드**: CPU 전체 + 스레드별 막대, RAM, GPU 사용률과 VRAM, C:/D: 여유 공간
  - 드라이브마다 막대 아래에 `읽기 48 MB/s  쓰기 18 MB/s  활성 20%` 한 줄. 활성은 작업 관리자의 "활성 시간"과 같은 값(그 1초 중 I/O가 걸려 있던 비율)이고, 60% 이상이면 색이 바뀐다. 쉬고 있는 값은 흐리게 표시된다.
  - 드라이브 문자(볼륨) 단위로 재기 때문에 한 디스크를 나눈 파티션도 따로 보인다. 관리자 권한은 필요 없다.
  - USB 메모리·외장 디스크·메모리 카드는 꽂으면 줄이 생기고 빼면 사라진다. "하드웨어 안전하게 제거"를 막지 않도록 이런 드라이브는 핸들을 열어 두지 않는다.
- **게임 모드**: `RAM 62%  GPU 99%  ↓7K ↑2K  PING 15ms` 한 줄만 표시. RAM·GPU는 60% 이상일 때만 색이 바뀐다.
  - ↓/↑: 인터넷으로 나가는 어댑터(Windows 라우팅 기준) 하나의 받기/보내기 속도. 일반 모드에서는 재지 않는다.
  - PING: `perf_overlay.json`의 `"ping_host"`(기본 `1.1.1.1`)로 1초마다 보내는 ping. 80 ms 이상 주황, 150 ms 이상 빨강, 응답이 없으면 빨간 `--`. 게임 서버까지의 핑은 아니고 인터넷 회선 상태를 보는 값이다. 게임 서버 주소를 알면 그 주소로 바꿀 수 있다(ICMP에 응답하는 서버만).
- **기본은 게임 모드, 바탕화면에서만 상세 표시**: 평소에는 게임 모드 한 줄로 떠 있다가, 바탕화면이 맨 앞에 오면(Win+D, 바탕화면 클릭) 일반 모드의 상세 표시로 바뀌고, 다른 창을 누르면 다시 한 줄로 돌아간다.
  - 작업 표시줄·시작 메뉴·Alt+Tab·오버레이 설정 팝업을 여는 건 전환으로 치지 않는다.
  - 크기가 바뀔 때 오른쪽 끝(화면 아래쪽에 두었으면 아래 끝도)이 고정된다. 저장되는 위치는 한 줄 표시 기준이다.
  - 설정 팝업의 "바탕화면에서는 상세 표시"를 끄면 게임 모드가 늘 한 줄로 유지되고, "게임 모드"를 끄면 늘 상세 표시다.
  - 이 기능 이전의 설정 파일은 처음 실행할 때 한 번 게임 모드 켜짐으로 바뀐다.
- **자동 게임 모드**: 게임 모드를 꺼 둔 경우, 게임이 맨 앞에 오면 게임 모드로 바뀌고, 그 게임이 종료되면 원래대로 돌아간다. Alt+Tab으로 잠깐 나가는 건 종료로 치지 않는다.
  - 게임 판단 기준: Windows Game Bar가 인식한 게임 목록, 또는 Steam·Riot·Epic·GOG·Xbox 설치 폴더 안의 실행 파일
  - 못 잡는 게임은 `perf_overlay.json`의 `"extra_games"`에 실행 파일 이름(예: `"mygame.exe"`)을 넣는다.
  - 잘못 잡히는 프로그램은 `"not_games"`에 넣는다.
- **트레이 아이콘**: 좌클릭하면 설정 팝업이 열린다.
  - 오버레이 표시 (잠깐 숨기기)
  - 게임 모드
  - 바탕화면에서는 상세 표시
  - 위치 편집 (드래그로 이동, 더블클릭으로 완료)
  - 우측 상단으로 이동
  - 투명도
  - Windows 시작 시 실행
  - 언어 (한국어 / English, 처음엔 Windows 표시 언어를 따른다)
  - 종료

  우클릭하면 빠른 토글 메뉴가 나온다.
- **가벼움**: CPU 평균 0.03% 미만, 메모리 약 45 MB, GPU는 쓰지 않는다.

## 실행

```bash
pip install -r requirements.txt
pythonw perf_overlay.pyw
```

- GPU 수치는 NVIDIA 드라이버에 포함된 `nvml.dll`을 사용한다. NVIDIA GPU가 없으면 `N/A`로 표시된다.
- "Windows 시작 시 실행"은 작업 스케줄러에 현재 사용자 전용 로그온 작업(`PerfOverlay`, 15초 지연)으로 등록된다. 관리자 권한은 필요 없다.
- 콘솔 없이 실행할 때 생기는 오류는 `perf_overlay.log`에 남는다.
- 설정(위치, 투명도, 게임 모드, 표시할 드라이브)은 같은 폴더의 `perf_overlay.json`에 저장된다. 표시할 드라이브는 `"drives": ["C:\\", "D:\\"]`로 바꿀 수 있다. USB 저장소 자동 표시는 `"usb_drives": false`로 끈다.
