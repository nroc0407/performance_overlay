# Perf Overlay

Windows용 작은 성능 오버레이. 화면 구석에 항상 떠 있으면서 CPU / RAM / GPU / 네트워크 / 디스크 여유 공간을 보여준다.

- **클릭 통과**: 오버레이는 마우스를 무시하고 포커스도 가져가지 않는다. 게임이나 작업을 방해하지 않는다.
- **일반 모드**: CPU 전체 + 스레드별 막대, RAM, GPU 사용률과 VRAM, 네트워크 ↓/↑ 속도, C:/D: 여유 공간
- **게임 모드**: `RAM 62%  GPU 99%  ↓7K ↑2K` 한 줄만 표시. 60% 이상일 때만 색이 바뀐다.
- **자동 게임 모드**: 게임이 맨 앞에 오면 게임 모드로 바뀌고, 그 게임이 종료되면 원래대로 돌아간다. Alt+Tab으로 잠깐 나가는 건 종료로 치지 않는다.
  - 게임 판단 기준: Windows Game Bar가 인식한 게임 목록, 또는 Steam·Riot·Epic·GOG·Xbox 설치 폴더 안의 실행 파일
  - 못 잡는 게임은 `perf_overlay.json`의 `"extra_games"`에 실행 파일 이름(예: `"mygame.exe"`)을 넣는다.
  - 잘못 잡히는 프로그램은 `"not_games"`에 넣는다.
- **트레이 아이콘**: 좌클릭하면 설정 팝업이 열린다.
  - 오버레이 표시 (잠깐 숨기기)
  - 게임 모드
  - 위치 편집 (드래그로 이동, 더블클릭으로 완료)
  - 우측 상단으로 이동
  - 투명도
  - Windows 시작 시 실행
  - 언어 (한국어 / English, 처음엔 Windows 표시 언어를 따른다)
  - 종료

  우클릭하면 빠른 토글 메뉴가 나온다.
- **가벼움**: CPU 평균 0.03% 미만, 메모리 약 45 MB, GPU는 쓰지 않는다.

## 실행

```bash
pip install -r requirements.txt
pythonw perf_overlay.pyw
```

- GPU 수치는 NVIDIA 드라이버에 포함된 `nvml.dll`을 사용한다. NVIDIA GPU가 없으면 `N/A`로 표시된다.
- "Windows 시작 시 실행"은 작업 스케줄러에 현재 사용자 전용 로그온 작업(`PerfOverlay`, 15초 지연)으로 등록된다. 관리자 권한은 필요 없다.
- 콘솔 없이 실행할 때 생기는 오류는 `perf_overlay.log`에 남는다.
- 설정(위치, 투명도, 게임 모드, 표시할 드라이브)은 같은 폴더의 `perf_overlay.json`에 저장된다. 표시할 드라이브는 `"drives": ["C:\\", "D:\\"]`로 바꿀 수 있다.
